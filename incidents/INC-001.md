# INC-001 — ICMP Reconnaissance / Test Traffic

## Summary

Suricata detected ICMP traffic from the Kali test client to the Ubuntu target across the isolated LAB-IN/LAB-OUT path.

## Detection

- Signature: `SOC LAB ICMP Test`
- SID: `1000001`
- Protocol: ICMP
- Source: `10.10.10.10`
- Destination: `10.10.20.10`
- Sensor interface: `ens38`
- Action: `allowed`

## Investigation

The traffic was generated intentionally using:

```bash
ping -c 3 10.10.20.10
```

The destination was a lab-owned Ubuntu VM. The activity was therefore classified as controlled validation traffic rather than an external incident.
