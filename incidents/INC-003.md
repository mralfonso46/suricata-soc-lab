# INC-003 — Suspicious HTTP `/admin` Request

## Summary

Suricata detected an HTTP GET request for `/admin` from the Kali test client to the Ubuntu target.

## Detection

- Signature: `SOC LAB Suspicious HTTP URI`
- SID: `1000003`
- Protocol: TCP/HTTP
- Source: `10.10.10.10:45266`
- Destination: `10.10.20.10:80`
- Method: `GET`
- URI: `/admin`
- User-Agent: `curl/8.18.0`
- HTTP status: `404`
- Action: `allowed`

## Triggering Activity

```bash
curl http://10.10.20.10/admin
```

## Analyst Disposition

**Closed — Authorized Lab Test**

## Investigation Notes

The request produced a 404 response, meaning the requested path was not found by the temporary web server. The Suricata detection still correctly triggered because the rule matches the URI string `/admin`.
