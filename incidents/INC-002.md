# INC-002 — TCP SYN Port Scan

## Summary

Suricata detected a burst of TCP SYN packets from the Kali test client against the Ubuntu target.

## Detection

- Signature: `SOC LAB Possible TCP SYN Scan`
- SID: `1000002`
- Protocol: TCP
- Source: `10.10.10.10`
- Destination: `10.10.20.10`
- Sensor interface: `ens38`

## Triggering Activity

```bash
nmap -sS -p 1-1000 10.10.20.10
```

The scan reported TCP/22 as open and the remaining scanned ports as closed.

- `screenshots/10-port-scan-detection.png`
- `screenshots/13-incident-002-evidence.png`

The EVE records show repeated TCP SYN alerts across multiple destination ports.

## Analyst Disposition

**Closed — Authorized Lab Test**

## Tuning Considerations

A production implementation should distinguish approved scanners from unexpected reconnaissance and tune thresholds using normal network behavior.
